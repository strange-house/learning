# Learning 正式需求文档（v1.0 · 已冻结）

> 冻结日期：2026-11-23。据此搭建 App。
> 原则：功能以本文档为准；新增任何功能需先经本人同意。

## 1. 产品概述
| 项 | 内容 |
|---|---|
| 名字 | Learning |
| 定位 | 完全离线、给自己用、不限内容、计划型、低决策成本的学习 App |
| 平台 | Android 手机（单端，无云同步） |
| 主色 | 靛蓝 |
| 桌面名 | Learning |
| 首屏 | 打开默认进「今天」 |
| 图标 | 白底 + 简单图形（助手设计） |

## 2. 核心目标
降低「每天不知道干嘛」的决策成本。手段：**习惯自动出现 + 待办池无压力 + 软性未来排期**。

## 3. 界面结构（5 个 Tab）

### 今天（默认首页）
- 顶部：日期 + 「今天完成 X/Y」进度条
- 习惯：当天该做的习惯**自动出现**（非当日完全不显示）
- 今日计划：按优先级 **SSS→SS→S→A** 排序；打勾完成**留在原地**
- 接下来几天：软性、虚线弱化；明天/后天显示「明天/后天」，超过 2 天显示具体日期；可一键「今天做」
- 右下角「＋」快速添加

### 计划
- 待办池：无日期、无压力；每条可「今天做」「排到明天」
- 接下来几天：软性时间线（可指定具体日期）

### 日记
- 一天一篇，自由文字，可编辑 / 删除

### 备忘
- 便签：新建 / 再编辑 / 删除；右侧「…」；显示创建时间，保留修改时间（暂不展示）；可置顶

### 我的
- 统计：仅「习惯完成」（各习惯累计完成天数）
- 设置：深色模式、JSON 导出 / 导入、关于

## 4. 数据实体与字段
- **习惯**：标题 + 频次（每天 / 每周固定几天）+ 分类；**无优先级**
- **计划（今天）**：标题 + 分类 + 优先级（默认 A，可 S / SS / SSS）
- **待办池**：仅标题；**无优先级、无分类**（最低摩擦）
- **未来事项**：标题 + 日期（软性）；**无优先级、无分类**
- **日记**：日期 + 标题 + 正文
- **备忘**：内容 + 创建时间 + 修改时间 + 置顶标记

> 说明：待办池 / 未来事项「今天做」后，转成今日计划，自动给默认分类「其他」、默认优先级「A」，之后可在「…」里改。

## 5. 关键交互
- 编辑 / 删除：条目右侧「…」菜单
  - 计划：改优先级（A/S/SS/SSS）、编辑（标题/分类）、删除
  - 习惯：改频次、删除
  - 备忘：再编辑、删除
- 优先级：4 档 **A（默认）/ S / SS / SSS**，A 最低、SSS 最高
- 排序：按优先级高 → 低
- 分类：固定 4 个 —— 看书 / 学习 / 练习 / 其他

## 6. 明确不做（Out of scope）
- 连续打卡 / 连击天数、本周完成统计
- 任何提醒通知
- 搜索
- 时长、备注字段
- 云同步、账号、AI
